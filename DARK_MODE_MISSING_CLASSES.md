## Recommended Implementation Approach

### Step 1: Update Headings (text-ink-900)
All heading elements using `text-ink-900` should add `dark:text-ink-50`

### Step 2: Update Body Text (text-ink-500)
All body/secondary text using `text-ink-500` should add `dark:text-ink-400`

### Step 3: Update Tertiary Text (text-ink-600)
All tertiary text using `text-ink-600` should add `dark:text-ink-400`

### Quick Search & Replace Pattern
For most editors, you can use find-and-replace with regex:
- `text-ink-900([^d])` → `text-ink-900 dark:text-ink-50$1` (headings)
- `text-ink-500([^d])` → `text-ink-500 dark:text-ink-400$1` (secondary text)
- `text-ink-600([^d])` → `text-ink-600 dark:text-ink-400$1` (tertiary text)
